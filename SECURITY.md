# Security policy

## Supported versions

Only the latest release gets security fixes. The app updates itself, so please check you're
on the newest version before reporting.

## Reporting a vulnerability

Please don't report it in a public issue. Either use GitHub's private reporting (go to the
[Security tab](https://github.com/FarisHrvat/assayplot/security) and click
**Report a vulnerability**), or email [AssayPlot@pm.me](mailto:AssayPlot@pm.me).

Include what you found, how to reproduce it, and which version and operating system you use.
You'll get a reply within a week.
